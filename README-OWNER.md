# لوحة مالك محاكي القدرات

## الدخول لأول مرة

1. افتح `admin.html` أو اضغط «دخول المالك» أسفل الصفحة الرئيسية.
2. أدخل بريد المالك وكلمة مرور من 8 أحرف فأكثر.
3. اضغط «إنشاء حساب المالك لأول مرة».
4. افتح رسالة التأكيد التي تصل إلى البريد، ثم ارجع وسجّل الدخول.

## ما تتضمنه اللوحة

- إحصاءات بنك الأسئلة والمحاولات والنتائج.
- إضافة الأسئلة الكمية واللفظية وتعديلها وحذفها.
- تحديد المهارة والصعوبة والحالة والإجابة الصحيحة وشرح الحل.
- البحث والتصفية داخل بنك الأسئلة.
- عرض آخر 100 محاولة ونتائج القسمين الكمي واللفظي.

لوحة المالك محمية بصلاحيات قاعدة البيانات، ولا يكفي معرفة رابطها للوصول إلى البيانات.
